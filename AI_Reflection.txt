3. Technical decisions:
- Using `nanoid` for unique IDs to prevent collisions.
- Storing events in a Map for faster lookups.
- Using React Context to manage shared state and avoid prop drilling.
- Using Tailwind CSS for rapid responsive design.
- Implementing generic filters and reset functionality for usability.
